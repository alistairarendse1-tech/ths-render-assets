# THS Render Assets

Temporary public host for Studio-derived render assets used by the
`vidiq_compose` pipeline, which requires durable public HTTPS URLs.

**Contents:** 16:9 crops of Studio-generated graphics, and page stills
from NIST Handbook 44 (a US federal government work, public domain).

**Not hosted here:** third-party licensed material. Stock footage is
referenced directly from the provider CDN rather than redistributed.

This repository exists solely as a transfer mechanism and is expected
to be deleted once rendering is complete.
